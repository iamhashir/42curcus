# 42Cursus

Welcome to my 42Cursus journey! This repository serves as a comprehensive archive of all the projects I have completed during my time at 42, displaying my progression from a novice C programmer to a full-stack software engineer.

## 🚀 About 42

42 is a global education initiative that proposes a new way of learning technology: no teachers, no classrooms, 100% peer-to-peer learning. The curriculum is project-based and gamified, allowing students to learn at their own pace.

The "Cursus" is the main program, starting with low-level C programming and advancing through algorithms, graphics, networking, C++, and web development.

## � Skills Acquired

Through this curriculum, I have gained proficiency in:

## 💻 Usage

Most projects in this repository are written in **C** or **C++** and include a `Makefile` for compilation.

**Standard Instructions:**
1.  Navigate to a project directory: `cd rank2/push_swap`
2.  Compile the project: `make`
3.  Run the executable (e.g., `./push_swap ...`)
4.  Clean up object files: `make clean`
5.  Full cleanup: `make fclean`

_Note: All C code strictly follows the **42 Norm**, a rigorous set of coding style rules._
